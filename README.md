# JB Infermetry

Making everyday AI consumption transparent,
measurable, and accessible.

## Mission

JB Infermetry is an independent open-source
initiative designed to help people understand
the economics of everyday AI usage.

## Project Goals

- Translate AI model pricing into meaningful
  task-oriented cost estimates.
- Make AI consumption economics accessible
  to technical and non-technical users.
- Provide transparent and reproducible
  cost calculations.
- Promote responsible and informed AI usage.

## Engineering Approach

- Spec-Driven Development
- Architectural simplicity
- Privacy by design
- Automated testing
- Evidence-based delivery
- Build in Public

## Project Status

Early development — Foundation phase.

The initial release will focus on deterministic
cost estimation using publicly available
model pricing information.

## Disclaimer

Cost estimates are informational and may
differ from actual provider billing.

## Independence

JB Infermetry is an independent personal
project developed using public information
and independently authored source code.
